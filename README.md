# Fortalecida-no-Python

Pequeno projeto de estudo para reforçar os fundamentos de Python e manter uma rotina de prática.

## Arquivos

- `fundamentos_python.py`: exemplos organizados por assunto, incluindo strings, variáveis, operadores, condicionais, laços, coleções, funções, exceções e módulos.
- `sistema_escolar.py`: exercício prático de cadastro, listagem e busca de alunos, além do cálculo da média da turma.

## Requisitos

- Python 3.10 ou superior recomendado.
- Não são necessárias bibliotecas externas; os exemplos usam a biblioteca padrão do Python.

## Como executar

No terminal, dentro da pasta do projeto:

```bash
python3 fundamentos_python.py
```

Para executar o sistema escolar:

```bash
python3 sistema_escolar.py
```

## O que praticar

1. Execute cada arquivo e observe a saída.
2. Altere valores e teste diferentes condições.
3. Adicione novos recursos ao sistema escolar, como editar ou remover um aluno.
4. Como o sistema escolar mantém os dados apenas na memória, os cadastros são perdidos quando o programa é encerrado. Um próximo exercício pode ser salvar os dados em um arquivo JSON.

## Objetivo

Este repositório é um caderno de estudos em evolução. A prioridade é compreender os conceitos e praticar, não criar um sistema comercial completo.
